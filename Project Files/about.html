About the Project

Heritage Treasures: An In-Depth Analysis of UNESCO World Heritage Sites (2019)

Project Overview

This comprehensive project explores the rich dataset of UNESCO World Heritage Sites using advanced data visualization techniques in Tableau, integrated with a modern Flask web application.

By leveraging the power of interactive visualizations, stakeholders can gain deeper insights into the global heritage landscape, identify patterns, and make informed decisions to enhance the preservation and promotion of these invaluable cultural and natural sites.

Key Visualizations

Scenario 1: Heritage Sites by Country

This visualization represents each country as a block, with the size proportional to the number of heritage sites it contains. Key columns used: Country and Name_en.

  • Quick country comparison
  • Visual size representation
  • Comprehensive distribution view
Scenario 2: Heritage Sites at Risk

Pie chart displaying the proportion of UNESCO sites listed as being in danger, segmented into 'In Danger' and 'Not in Danger' categories. Key columns: Danger and Name_en.

  • Risk assessment visualization
  • Threat severity analysis
  • Conservation priority insights
Scenario 3: Regional Inscription Trends

Line chart showing trends of new site inscriptions over years, segmented by region. Key columns: Date_inscribed and Region.

  • Temporal analysis
  • Regional growth patterns
  • Historical trend identification
